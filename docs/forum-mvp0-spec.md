# AngryDucks 论坛 MVP0 规格

> 日期：2026-11-03
> 状态：已确认，开工。细节以后慢慢改。
> 代码：`forum/`

## 本轮要回答的问题

人会不会在按 tag 组织的论坛里持续发话题，会不会主动填自己的产品卡片。

**及格线**：邀请 20 人跑 3 周，至少 15 个话题，一半以上的话题有别人回复，至少 10 人填了产品卡片。

## 账号与权限

| 问题 | 定义 |
|---|---|
| 注册 | 邀请码 + 邮箱 + 密码，不发邮件 |
| 忘记密码 | 管理员后台重置，生成临时密码 |
| 显示名 | 注册时填写，全站唯一（不区分大小写），可以改 |
| 头像 | 不做，显示首字母 |
| 个人页 | 显示名、一句话简介、产品卡片、发过的话题 |
| 未登录 | 只能看到登录和注册页 |
| 管理员 | 数据库标记。可删任意话题和回复、封号、生成邀请码、重置密码 |
| 举报、自助注销 | 不做 |

## 内容与呈现

| 问题 | 定义 |
|---|---|
| 话题 | 标题必填，不超过 100 字符；正文必填，不超过 6000 字符 |
| 回复 | 平铺，按时间正序；正文上限与话题相同，6000 字符 |
| 编辑与删除 | 作者可编辑，标注"edited"；删除后保留位置显示"deleted" |
| **Tag** | **自由标注**：作者发帖时自己写 1 到 3 个。统一转小写，空格转连字符，去掉 `#`，只保留各语言的字母、数字、`-`、`_`，每个不超过 32 字符 |
| 首页 | 顶部一排使用最多的 tag，下面是全部话题按热度排序；点 tag 只显示带该 tag 的话题 |
| 点赞 | 只能赞话题，每人一票，可撤销 |
| 热度 | (赞数 + 回复人数) / (发帖后小时数 + 2)^1.5，只有这一种排序 |
| 通知 | 顶部显示有新回复的话题数，只算自己发起或回复过的话题 |
| 产品卡片 | 名称、一句话、链接、状态（building / live / stopped），每人最多 10 张，创建时间倒序 |
| **界面语言** | **英文**，中文暂不做 |
| **内容语言** | **任意语言**。每条内容按文字系统自动识别语言，写入数据库并输出到 HTML 的 `lang` 属性；页面不禁用翻译；显示名和 tag 标记为不翻译。目的是让浏览器的 Google 翻译能把各语言的帖子翻成读者的语言 |

## 正文格式（2026-11-03 第二轮）

| 问题 | 定义 |
|---|---|
| 长度 | 话题和回复统一 6000 字符，按字符数计算，不区分语言 |
| 长文 | 不支持。超过 6000 字符的文章发到 Substack、个人博客或 GitHub 等处，帖子里写摘要并附全文链接。发帖页顶部常驻这条规则 |
| 格式 | 正文按 Markdown 显示：段落、单个换行即换行、列表、加粗、斜体、链接、引用、标题、表格、行内代码 |
| 原始 HTML | 一律当作文字显示 |
| 代码 | 不在论坛分享。正文里出现代码块（三个反引号或波浪号）直接拒绝，提示把代码放在仓库或文档里再贴链接。行内代码允许，用来写命令名、工具名 |
| 图片 | 任何地方都不显示。正文里的图片语法显示为文字链接 "[image: 说明]" |
| 上传 .md | 只在发新话题时可用。点 Load file 后把文件内容填进表单，不直接发出，由作者确认后再发 |
| 上传规则 | 只收 .md / .markdown / .txt，不超过 100 KB；开头的 "# 标题" 自动填进标题栏；代码块删除并留一行 "[code omitted, see the full version]" |
| 上传超长 | 按段落截断，留出约 120 字符给链接，末尾预填 "Full version: "，提示作者改写成摘要并贴上全文链接 |

## 防刷（2026-11-03 第二轮）

| 层 | 规则 |
|---|---|
| 准入 | 邀请码注册，机器人拿不到邀请码就进不来 |
| 每分钟 | 每人最多 3 条内容 |
| 每天 | 每人 24 小时内最多 30 条内容 |
| 重复 | 同一个人 24 小时内不能发完全相同的正文 |
| 登录 | 同一账号连续失败 5 次锁 15 分钟 |
| 待定 | Cloudflare Turnstile 人机验证，放在注册和登录页，需要在 Cloudflare 后台创建一个 widget |

## 安全与上线

| 问题 | 定义 |
|---|---|
| 防注入脚本 | 所有用户内容渲染前转义 |
| 防跨站提交 | Cookie 设为 SameSite=Lax，且所有 POST 校验 Origin |
| 防刷 | 见上面的防刷一节 |
| 登录有效期 | 30 天 |
| 技术栈 | Cloudflare Workers + D1，服务端直接输出 HTML，不用前端框架 |
| 域名 | `community.angryducks.net`（管理员注册 `angryducks.net`） |
| 备份 | 每周手动导出 D1 到本地 |
| 数据结构 | 话题和回复同在 `content` 表；tag 关联表带 `source` 字段（author / ai），为以后 AI 打标签留口子 |

## 已知取舍

1. 邀请码代替邮箱验证：忘记密码只能找管理员，正式开放注册前要补邮箱验证。
2. 全站登录后才能看：没有搜索引擎流量，内容不能直接分享到群外。
3. 不分享代码：代码块被拒绝，只允许行内代码。
4. 自由 tag：会出现同义 tag 分裂（agent / agents / ai-agent），第一轮观察，不处理。
5. 语言自动识别只按文字系统判断：中日韩、俄文、阿拉伯文等能识别；拉丁字母的语言（英、法、西、德等）一律标为英文。
